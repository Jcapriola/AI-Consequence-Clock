How the clock counts

The AI Consequence Clock is a measurement layer, not a complete global sensor. Agents may discover candidates. Evidence verifies. Sources remain visible. Headline numbers are derived only from structured fields. Title-text inference is forbidden.

Two independent axes

Review state and evidence grade are not the same thing.

Verification status (workflow)

  • VERIFIED — Key claims supported by a primary source, or by multiple independent reliable sources.
  • CORROBORATED — At least two independent secondary sources agree. One article is not enough.
  • REPORTED — A credible report exists; material facts or sources remain thin.
  • UNDER REVIEW / REJECTED — Queue states.

Evidence grade (what is actually attached)

  • PRIMARY — Filing, court/tribunal record, vendor advisory, official government notice, CVE record from the issuing authority.
  • INDEPENDENT_SECONDARY — Reputable newsroom or original research report that is not a roundup of other roundups.
  • ROUNDUP — Timeline, incident-database explorer page, or secondary compilation.
  • SUBMISSION — Community submission awaiting stronger sources.

Grade is assigned from the sources listed on the record, not from knowledge that a better source exists somewhere else. One Bloomberg link is INDEPENDENT_SECONDARY and, by itself, REPORTED — not CORROBORATED.

Headline rule

A record enters headline totals only when verification_status ∈ {VERIFIED, CORROBORATED} and evidence_grade ∈ {PRIMARY, INDEPENDENT_SECONDARY}. ROUNDUP and SUBMISSION records remain visible in the feed.

Differentiating fields

  • causal_role — agent_initiated / agent_executed / human_used_ai / model_only / unknown. Agent-caused counts use this field only.
  • adversary — attacker / no_attacker / research_demo / unknown.
  • authorization_evidence — signed_artifact / independent_execution_proof / policy_only / ui_confirmation / human_approval / none_documented / unknown.
  • unauthorized_claim — true / false / unknown. Counted only when explicitly true.
  • reversibility — rolled_back / irreversible / unknown.
  • consequence_class — data / money / infrastructure / legal / safety / other.
  • disclosure_lag_days — disclosure_date minus incident_date when both are known.

Do not conflate these two metrics

Unauthorized AI actions counts unauthorized_claim = true. That is a claim that the action was outside documented approval, scope, or policy.

Sourced cases lacking documented execution-time authorization counts authorization_evidence = none_documented. Missing proof is not the same as proven unauthorized action. Harmful outcome alone does not set either field.

Dates and money

Incident date and disclosure date stay separate. Confirmed monetary amounts are never mixed with estimates. Confirmed money enters headlines only on headline-eligible records.
